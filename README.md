# تنظيم حضور أعضاء نقابة المبرمجين العراقيين — ITEX 2026

صفحات ثابتة بالكامل، مستضافة على **GitHub Pages** فقط (بدون Render أو
Vercel أو أي خدمة خارجية) لتنظيم جدول حضور أعضاء نقابة المبرمجين
العراقيين الـ23 في بوث النقابة بمعرض ITEX 2026 (معرض بغداد الدولي)،
للأيام: الأربعاء 30/9، الخميس 1/10، الجمعة 2/10، السبت 3/10 — من الساعة
10:00 صباحاً حتى 8:00 مساءً.

## الفكرة

- كل عضو من الـ23 له **رابط خاص** (بدون كلمة مرور أو حساب) يفتحه من هاتفه
  ويحدد حضوره لكل يوم من الأيام الأربعة: **يوم كامل / صباحي (10-3) /
  مسائي (3-8) / غير متاح**. يمكنه العودة لاحقاً وتعديل اختياره.
- لوحة إدارة (`admin.html`) تعرض جدول الجميع مصنّفين حسب مناصبهم،
  وملخصاً يومياً لعدد الحاضرين بكل شفت مع تنبيه عند عدم وجود أي تغطية
  لشفت معيّن، وتسمح بتعديل حضور أي شخص عند الحاجة.
- **لا يوجد سيرفر إطلاقاً.** البيانات تُخزَّن في ملف `data/roster.json`
  داخل هذا المستودع نفسه، وصفحة الويب تقرأه وتعدّله مباشرة عبر GitHub
  API من المتصفح.

## ⚠️ نقطة أمان مهمة يجب معرفتها

بما أن هذا موقع ثابت بدون سيرفر، لا يوجد مكان لإخفاء أي "سر" — ملف
`github-config.js` يحوي مفتاح وصول (token) **ظاهر لأي شخص يفتح مصدر
الصفحة**. هذا المفتاح محدود بحيث يعمل **فقط على هذا المستودع الواحد**
(لا يمكنه لمس حسابك أو أي مستودع آخر)، لكن من الناحية العملية أي شخص
يحصل عليه يقدر يعدّل أو يحذف أي ملف في هذا المستودع تحديداً. تم قبول
هذه المخاطرة لأن الموضوع داخلي وقصير المدة (أيام المعرض فقط). لإلغاء
الوصول لاحقاً: احذف التوكن من GitHub Settings → Developer settings →
Fine-grained tokens.

كلمة مرور لوحة الإدارة (`ADMIN_PASSWORD` في `github-config.js`) هي
رادع بسيط فقط وليست حماية حقيقية للسبب نفسه — أي شخص يفتح مصدر الصفحة
يراها.

## النشر (مرة واحدة فقط)

1. **أنشئ مفتاح وصول محدود بهذا المستودع فقط:**
   افتح https://github.com/settings/personal-access-tokens/new
   - **Repository access** → **Only select repositories** → اختر
     `sakran707/itex2026-attendance`
   - **Permissions** → **Repository permissions** → **Contents** →
     **Read and write**
   - اضغط **Generate token** وانسخه (يبدأ بـ `github_pat_...`).
2. الصق التوكن في `github-config.js` (القيمة `GITHUB_TOKEN`)، وغيّر
   `ADMIN_PASSWORD` لكلمة مرور من اختيارك، واحفظ.
3. **فعّل GitHub Pages:**
   من صفحة المستودع → **Settings** → **Pages** → تحت **Build and
   deployment**: **Source** = **Deploy from a branch**، **Branch** =
   `main` و `/ (root)` → **Save**.
4. انتظر دقيقة، الرابط يظهر أعلى نفس الصفحة (Settings → Pages) بالشكل:
   `https://sakran707.github.io/itex2026-attendance/`

هذا هو الرابط النهائي — لا حاجة لأي شيء إضافي بعدها.

## الحصول على روابط الأعضاء

افتح `admin.html` من نفس الرابط (مثلاً
`https://sakran707.github.io/itex2026-attendance/admin.html`)، سجّل
دخول بكلمة المرور، ومن تبويب "جدول الأعضاء" اضغط "نسخ الرابط" أمام كل
شخص وأرسله له (واتساب مثلاً).

## التشغيل محلياً

لا حاجة لأي تثبيت — هذه صفحات HTML/JS عادية. افتح `index.html` بأي
خادم ملفات محلي بسيط (المتصفح يرفض `fetch` من `file://` مباشرة):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000/?t=<أحد الرموز من data/roster.json>
```

## البنية

```
data/roster.json       البيانات المشتركة: الأشخاص الـ23 وحضورهم — يُقرأ ويُعدَّل عبر GitHub API
github-config.js        إعدادات المستودع + التوكن (عام بالضرورة، انظر تحذير الأمان أعلاه)
github-store.js         القراءة/الحفظ في data/roster.json عبر GitHub Contents API (مع إعادة محاولة عند التعارض)
index.html               صفحة الشخص (يفتحها برابطه الخاص ?t=TOKEN)
attendance-app.js        منطق صفحة الشخص
admin.html               لوحة الإدارة
admin-app.js             منطق لوحة الإدارة (دخول بكلمة مرور + الجدول + الملخص + تعديل أي شخص)
style.css                التنسيق المشترك (عربي RTL، متجاوب مع الهاتف)
```
