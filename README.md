# تنظيم حضور أعضاء نقابة المبرمجين العراقيين — ITEX 2026

تطبيق مستقل (Node.js + Express + PostgreSQL) لتنظيم جدول حضور أعضاء نقابة
المبرمجين العراقيين الـ23 في بوث النقابة بمعرض ITEX 2026 (معرض بغداد
الدولي)، للأيام: الأربعاء 30/9، الخميس 1/10، الجمعة 2/10، السبت 3/10 —
من الساعة 10:00 صباحاً حتى 8:00 مساءً.

## الفكرة

- كل عضو من الـ23 له **رابط خاص** (بدون كلمة مرور أو حساب) يفتحه من هاتفه
  ويحدد حضوره لكل يوم من الأيام الأربعة: **يوم كامل / صباحي (10-3) /
  مسائي (3-8) / غير متاح**. يمكنه العودة لاحقاً وتعديل اختياره.
- لوحة إدارة محمية بكلمة مرور واحدة (`ADMIN_PASSWORD`) تعرض جدول الجميع
  مصنّفين حسب مناصبهم، وملخصاً يومياً لعدد الحاضرين بكل شفت مع تنبيه
  عند عدم وجود أي تغطية لشفت معيّن.
- قاعدة بيانات PostgreSQL واحدة مشتركة — كل التحديثات فورية ومرئية للجميع
  من لوحة الإدارة، لا حاجة لتزامن يدوي.

## النشر المجاني على Render (رابط مباشر، بدون إدارة سيرفر)

1. افتح https://dashboard.render.com وسجّل دخول بـ **"Continue with GitHub"**
   (نفس حساب GitHub الذي يملك هذا المستودع — بدون كلمة مرور جديدة).
2. من اللوحة: **New → Blueprint**، واختر هذا المستودع
   (`itex2026-attendance`). يقرأ Render ملف `render.yaml` تلقائياً وينشئ:
   - خدمة ويب مجانية (Node.js) تعطيك رابطًا فوريًا على شكل
     `https://itex2026-attendance-xxxx.onrender.com`
   - قاعدة بيانات PostgreSQL مجانية مرتبطة تلقائياً عبر `DATABASE_URL`.
3. عند السؤال عن القيم، أدخل فقط `ADMIN_PASSWORD` (كلمة مرور قوية من
   اختيارك للوحة الإدارة) — البقية (`SESSION_SECRET`, `DATABASE_URL`)
   تُولَّد وتُربط تلقائياً.
4. اضغط **Apply** وانتظر دقيقة إلى دقيقتين حتى يكتمل النشر، ثم افتح
   الرابط الذي يعطيك إياه Render — هذا هو الرابط النهائي.

> ملاحظة: قاعدة بيانات Render المجانية تُحذف تلقائياً بعد 30 يوماً من
> إنشائها — كافية جداً لمعرض مدته 4 أيام، لكن لا تصلح كأرشيف دائم. إن
> احتجت الاحتفاظ بالبيانات لاحقاً، صدّرها من لوحة الإدارة (تبويب "جدول
> الأعضاء") قبل انتهاء الفترة، أو رقِّ قاعدة البيانات لخطة مدفوعة من
> إعدادات Render.

## التشغيل محلياً

يحتاج PostgreSQL مثبت محلياً (أو أي قاعدة PostgreSQL يمكن الوصول إليها).

```bash
npm install
cp .env.example .env   # ثم عدّل ADMIN_PASSWORD و SESSION_SECRET و DATABASE_URL
npm start
```

يفتح على `http://localhost:3000`. لوحة الإدارة على `/admin.html`.

عند أول تشغيل يتم إنشاء الجداول تلقائياً وزرع الأشخاص الـ23 بأسمائهم
ومناصبهم كما وردت بالضبط، كل واحد برابط وصول عشوائي فريد.

## الحصول على روابط الأعضاء

سجّل دخول لوحة الإدارة (`/admin.html`) بكلمة المرور، ومن تبويب "جدول
الأعضاء" اضغط "نسخ الرابط" أمام كل شخص وأرسله له (واتساب مثلاً).
الرابط بالشكل: `https://your-app.onrender.com/?t=<token>`.

## النشر على أي سيرفر آخر (VPS / أي مزوّد يدعم Node.js + PostgreSQL)

1. ارفع المشروع إلى السيرفر (`git clone` أو رفع الملفات).
2. `npm install --omit=dev`
3. أنشئ ملف `.env` بكلمة مرور وسر جلسة قويين، ورابط اتصال PostgreSQL.
4. شغّله خلف مدير عمليات مثل PM2 أو systemd:
   ```bash
   pm2 start server.js --name itex2026-attendance
   ```
5. ضع خادم عكسي (Nginx) أمامه مع HTTPS.

## البيئة (متغيرات `.env`)

| المتغير | الوصف |
|---|---|
| `PORT` | المنفذ (افتراضي 3000) |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة — **غيّرها قبل النشر** |
| `SESSION_SECRET` | سر توقيع جلسة الإدارة — **غيّرها قبل النشر** |
| `DATABASE_URL` | رابط اتصال PostgreSQL |

## البنية

```
render.yaml           تعريف النشر على Render (خدمة ويب + قاعدة بيانات مجانية)
server.js              نقاط الـ API (عامة + إدارية) وتقديم الملفات الثابتة
db.js                  إنشاء الجداول وزرع الأشخاص الـ23 في PostgreSQL
attendanceRules.js     الأيام الأربعة الثابتة، أنواع الحضور، وأوقاتها — مصدر واحد
public/index.html      صفحة الشخص (يفتحها برابطه الخاص ?t=TOKEN)
public/attendance.js   منطق صفحة الشخص
public/admin.html      لوحة الإدارة
public/admin.js        منطق لوحة الإدارة (تسجيل الدخول + الجدول + الملخص)
public/style.css       التنسيق المشترك (عربي RTL، متجاوب مع الهاتف)
```
