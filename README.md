# تنظيم حضور أعضاء نقابة المبرمجين العراقيين — ITEX 2026

تطبيق مستقل (Node.js + Express + SQLite) لتنظيم جدول حضور أعضاء نقابة
المبرمجين العراقيين الـ23 في بوث النقابة بمعرض ITEX 2026 (معرض بغداد
الدولي)، للأيام: الأربعاء 30/9، الخميس 1/10، الجمعة 2/10، السبت 3/10 —
من الساعة 10:00 صباحاً حتى 8:00 مساءً.

## الفكرة

- كل عضو من الـ23 له **رابط خاص** (بدون كلمة مرور أو حساب) يفتحه من هاتفه
  ويحدد حضوره لكل يوم من الأيام الأربعة: **يوم كامل / صباحي (10-3) /
  مسائي (3-8) / غير متاح**. يمكنه العودة لاحقاً وتعديل اختياره.
- لوحة إدارة محمية بكلمة مرور واحدة (`ADMIN_PASSWORD`) تعرض جدول الجميع
  مصنّفين حسب مناصبهم، وملخصاً يومياً لعدد الحاضرين بكل شفت مع تنبيه
  عند عدم وجود أي تغطية لشفت معيّن.
- قاعدة بيانات SQLite واحدة مشتركة — كل التحديثات فورية ومرئية للجميع
  من لوحة الإدارة، لا حاجة لتزامن يدوي.

## التشغيل محلياً

```bash
npm install
cp .env.example .env   # ثم عدّل ADMIN_PASSWORD و SESSION_SECRET
npm start
```

يفتح على `http://localhost:3000`. لوحة الإدارة على `/admin.html`.

عند أول تشغيل يتم إنشاء قاعدة البيانات (`data/attendance.db`) تلقائياً
وزرع الأشخاص الـ23 بأسمائهم ومناصبهم كما وردت بالضبط، كل واحد برابط
وصول عشوائي فريد.

## الحصول على روابط الأعضاء

سجّل دخول لوحة الإدارة (`/admin.html`) بكلمة المرور، ومن تبويب "جدول
الأعضاء" اضغط "نسخ الرابط" أمام كل شخص وأرسله له (واتساب مثلاً).
الرابط بالشكل: `https://yourdomain.com/?t=<token>`.

## النشر على أي سيرفر (VPS / أي مزوّد يدعم Node.js)

1. ارفع المشروع إلى السيرفر (`git clone` أو رفع الملفات).
2. `npm install --omit=dev`
3. أنشئ ملف `.env` بكلمة مرور وسر جلسة قويين وعشوائيين.
4. شغّله خلف مدير عمليات مثل PM2 أو systemd:
   ```bash
   pm2 start server.js --name itex2026-attendance
   ```
5. ضع خادم عكسي (Nginx) أمامه مع HTTPS.

قاعدة البيانات ملف واحد (`data/attendance.db`) — يكفي نسخه احتياطياً
بشكل دوري.

## البيئة (متغيرات `.env`)

| المتغير | الوصف |
|---|---|
| `PORT` | المنفذ (افتراضي 3000) |
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة — **غيّرها قبل النشر** |
| `SESSION_SECRET` | سر توقيع جلسة الإدارة — **غيّرها قبل النشر** |
| `DB_PATH` | مسار ملف قاعدة البيانات |

## البنية

```
server.js            نقاط الـ API (عامة + إدارية) وتقديم الملفات الثابتة
db.js                إنشاء/فتح قاعدة بيانات SQLite وزرع الأشخاص الـ23
attendanceRules.js   الأيام الأربعة الثابتة، أنواع الحضور، وأوقاتها — مصدر واحد
public/index.html    صفحة الشخص (يفتحها برابطه الخاص ?t=TOKEN)
public/attendance.js منطق صفحة الشخص
public/admin.html    لوحة الإدارة
public/admin.js      منطق لوحة الإدارة (تسجيل الدخول + الجدول + الملخص)
public/style.css     التنسيق المشترك (عربي RTL، متجاوب مع الهاتف)
```
